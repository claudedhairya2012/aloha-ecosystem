## 📦 Quick Installation (Local Python Engine)

Install directly from GitHub via `pip`:
```bash

git clone https://github.com/claudedhairya2012/aloha-ecosystem.git
cd aloha-ecosystem
pip install -r requirements.txt

# Run the 5-Stage Multi-Agent Simulation
python demo.py

# Launch the Local Hybrid Server (http://127.0.0.1:8080)
python server.py
